# Reproducibility package scope and distribution

## Scientific scope

The released source code executes numerical replay from frozen per-query and per-configuration results. It is not a fully runnable reimplementation of training and matching from original images. This boundary is intentional and must be stated in the repository README and any manuscript Data Availability Statement.

## Redistribution

The package contains no journal-manuscript source, PDF, manuscript figures or editable illustration files. Original third-party photographs and weights are not mirrored. Derived query/cell outputs do not include original dataset photographs or pretrained weights. Use of source datasets remains subject to the respective benchmark terms. No third-party code licence is implied.

## Attribution

PEAV uses separately sourced retrieval and matching techniques (CosPlace, R2Former, DISK, ALIKED, LightGlue, MAGSAC++), and frozen evidence inherited from earlier research-stage pipelines. Their algorithms and datasets are not claimed as newly developed resources in this package.

## Scholarly integrity

The repository must not be used to replace a frozen test verdict with exploratory post-hoc results. Any new policy tuning or model selection on protected outcomes is outside the confirmatory evaluation.
